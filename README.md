# BL Blossom & Co. — Website Files

Everything for your website is in this folder, ready to upload to GitHub exactly as-is.

## What's here
- `index.html` — your website (upload this to the root of the repo)
- `content.json` — the file your future login dashboard edits
- `admin/` — your login dashboard (keep this folder as-is)
- `images/uploads/` — where photos you upload later will land (keep this folder, even though it's empty for now)

## Quick start: getting this onto GitHub

1. Go to [github.com](https://github.com) and create a free account, if you don't have one yet — this part has to happen on your end, since it needs your own email and password to sign in.
2. Once you're signed in, click the **+** in the top right → **New repository**. Name it `bl-blossom-website`, then click **Create repository**.
3. On the new repository's page, click **uploading an existing file**.
4. Drag in every file and folder from inside this zip (`index.html`, `content.json`, `admin`, `images`) — all at once, all together, into that one upload screen.
5. Scroll down and click **Commit changes**.

That's it — your repository now has everything it needs. From here, follow **BL-Blossom-Setup-Guide.md** (sent earlier in our chat) for the rest: connecting Netlify to this repository, turning on your login dashboard, and moving your domain over.
